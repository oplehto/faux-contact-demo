# Faux Contact

[Open the style guide](https://oplehto.github.io/faux-contact-demo/) or [launch Sprite Lathe](https://oplehto.github.io/faux-contact-demo/renderer/).

The retrofuturistic guide combines a rolling CRT raster, dithered pixel graphics and amber film titles. The renderer lets you turn a split coupling, torus or trefoil knot and export transparent PNG sprites.

GitHub Pages serves the root of `main`. The HTML, CSS, JavaScript and artwork also work locally. Open `index.html` or `renderer/index.html` in a browser.
